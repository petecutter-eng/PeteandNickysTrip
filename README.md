# Trip Planner

A phone-first trip planner that runs entirely in the browser: a trip calendar, day details, a packing checklist for the whole group, AI import of any itinerary, and an on-demand daily briefing. There's no install, account or backend.

**Open it:** https://petecutter-eng.github.io/PeteandNickysTrip/
